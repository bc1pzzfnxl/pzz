## Details

- **[MDXCN](https://www.mdxcn.dev/llms.txt)** — Markdown / MDX authoring. Markdown-friendly react components for mdx.
- **[Numbers](https://numbers.sfinterface.com/)** — Displaying numbers, stats, metrics. Numbers that move the way they should.
- **[VoidAuth](https://voidauth.app/)** — Adding authentication. Single Sign-On for Your Self-Hosted Universe.
- **[Kugiri](https://edoardolunardi.github.io/kugiri/)** — Animating text appearance. Splits text into lines, words and characters exactly where the browser already broke it.
- **[Component Gallery](https://component.gallery/components/)** — Choosing UI wording, components, patterns. An up-to-date repository of interface components based on examples from the world of design systems, designed to be a reference for anyone building user interfaces.
- **[SVGL](https://svgl.app/)** — Adding logos / brand marks. A beautiful library with SVG logos.
- **[ShadScan](https://www.shadscan.com/docs)** — Auditing a shadcn/ui codebase. Run Shadscan, check rendered UI at mobile and desktop widths, inspect a progress-bar score, launch a coding agent, and enforce score thresholds.
- **[env.style](https://www.env.style/)** — Local development (environment favicons). Style your favicon with colors or custom icons, so every tab shows where you are.
- **[shieldcn](https://shieldcn.dev/llms.txt)** — README badges. Beautiful README badges.
