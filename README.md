# pzz

Agent guidance plus a UI toolbox, published for reuse across projects.

## What's here

| Path | Purpose |
| --- | --- |
| `AGENTS.md` | Global agent guidance (behaviour rules). |
| `tools.json` | The hand-maintained tool list (`name`, `url`, `use`). |
| `toolbox.md` | Generated toolbox doc (descriptions extracted from each source). |
| `skills/frontend-toolbox/` | Skill listing the preferred UI/frontend tools. |
| `templates/repo-AGENTS.md` | Starter `AGENTS.md` for a new repository. |

## Install the skill

```bash
bunx skills add bc1pzzfnxl/pzz
```

## Toolbox

<https://raw.githubusercontent.com/bc1pzzfnxl/pzz/main/toolbox.md>

## Regenerate

```bash
bun scripts/generate.mjs
```

`tools.json` is the only hand-maintained input. `toolbox.md` and the skill table
are generated by extracting each tool's description from its `llms.txt` or page
metadata.
